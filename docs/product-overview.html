What the plugin does

Looper is a visual query builder for EtchWP. Use it to choose the content your visitors see, from a simple list of recent posts to a query that combines taxonomy, meta, date, and relationship conditions. The generated PHP stays visible as you work, so you can see exactly what the controls produce.

Looper handles the data query. You continue designing the repeated content in Etch, using your own elements, components, and dynamic data.

Choose what repeats

Build queries for posts and public custom post types, Media Library attachments, taxonomy terms, or WordPress users. Use Main Query for archive and search templates where the current URL supplies the query context. Attachment queries support file types, parent posts, and attachment taxonomies such as Etch Collections.

Set count, sorting, status, and offset, then add only the filters you need. Taxonomy filters include a term-name lookup. Meta filters work with stored keys and values, including manually entered keys. Date filters provide calendar pickers and relative dates.

Combine your filters

Nested AND/OR groups let you express conditions such as “in either of these categories, with a rating above a threshold, and published within this date range.” Advanced adds selection, author, search, hierarchy, and pagination controls where the query source supports them. It stays focused on selecting, filtering, and ordering content rather than database tuning.

Mark a supported scalar option as an Argument to reuse a definition with different values. For example, $count ?? 6 supplies a default of six records while allowing another count when the loop is used. List settings use explicit values.

Preview the data. Copy the dynamic key.

Run preview to inspect one matching record. Expand its fields and copy an Etch expression such as {item.title} directly into your loop's content. Preview uses the argument defaults entered in Looper. Main Query results need to be checked in the relevant archive or search template.

Load an existing supported query to edit it, save a definition into the Loop Manager, insert a new loop element, or apply the definition to the selected loop. Keeping a query's key updates that definition wherever it is referenced; changing the key creates another. Finish with Etch Save to persist editor changes.

Get started

  1. Install the release ZIP, activate Looper, and open its button in Etch's left toolbar.
  2. Choose a source, name the query, and configure its options and filters.
  3. Inspect the generated PHP and run a sample preview.
  4. Choose the appropriate Etch action, then save in Etch.

Requirements

  • WordPress 7.1 or later and PHP 8.3 or later.
  • Etch with its public Loop API for editor integration. Tested with Etch 1.7.1.
  • Administrator access or the manage_options capability. User previews also require list_users.
  • Meta Box Relationships only when building queries that use that integration.

Updates through WordPress

Stable versions are published as GitHub releases and appear alongside your other WordPress plugin updates. Install them normally or opt into WordPress auto-updates. Your site does not need a GitHub token. Download the release asset named looper-for-etch.zip; GitHub's separate source archives are for development.

Good to know

Does Looper save the page?

Its actions update the editor session. Use Etch Save to persist those changes. Updating a shared definition changes every loop that references that definition.

What happens if I deactivate or uninstall Looper?

For the current release, keep Looper active while testing queries you create with it. Removing it does not delete your content, page layouts, or saved Etch queries, but you lose:

  • Looper's query builder, preview, and query-editing tools.
  • Support for queries saved in Looper's special format. Those loops may stop displaying results until their saved settings are converted to ordinary Etch queries.
  • Looper's extra check that stops relationship results when the required Meta Box Relationships extension is missing.

Ordinary native Etch queries continue working. Tests confirmed that the same query features can run without Looper after conversion, but the current release does not automatically convert existing queries. Keep any field or relationship plugins that supply your data active too. See the native-query test results and current limitations.

Can it edit every Etch loop?

It loads supported WordPress query definitions. JSON loops, dynamic-data arrays, custom PHP callbacks, and queries returning only IDs or counts stay outside the visual builder.

Does it work across a multisite network?

Queries use each site's own content and Etch registry. Cross-site loops and a network-wide query library are outside this release. A full multisite/Etch test matrix is still pending.
