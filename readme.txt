Visual WordPress queries for Etch, with nested filters, PHP output, dynamic-field previews, and direct editor integration.

== Description ==
Build post, attachment, term, user, and archive/search Main Query loops. Combine taxonomy, meta, date, selection, and ordering controls. Keep Looper active for complex saved definitions. Etch is required for editor integration.

Distributed through GitHub releases. Updates appear in the standard WordPress Plugins/Updates interface. This is not a WordPress.org-hosted plugin.

== Installation ==
Upload the release ZIP through Plugins > Add New > Upload Plugin. Activate Looper, reload Etch, and use its left-toolbar button. Use Etch Save after adding or editing a query.
