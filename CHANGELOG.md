# Changelog

## 0.8.0

- Focus Advanced on selecting, filtering, and ordering visitor-facing content; remove execution, output-format, and permission-mode controls. Keep previews scoped to the current site; cross-site queries are outside this release.
- Move Ignore sticky promotion into Query options, widen labels with responsive stacking, and remove the Fixed value label.
- Add contextual explanations and official WordPress references.
- Add stable GitHub releases to WordPress's native update mechanism, with versioned packages, bounded HTTPS requests, compatibility metadata, caching, and SHA-256 verification.
- Harden metadata discovery permissions, relationship validation, query error handling, and prepared/cached key lookups.
- Publish portable query, editor-action, accessibility, and updater tests with release automation.
